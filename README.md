# Mail Visualizer

## 概要

Mbox・EML形式のメールデータを解析し、Excel・HTML・印刷用HTML・TXTへ出力するツール。

現在の対応形式

- mbox
- eml
- メール形式のtxt

将来的には

- Becky!
- Outlook
- Thunderbird

へ対応予定。
